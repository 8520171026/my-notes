小白版 · 3 分钟上手

一句话它是啥

你电脑上跑着 Nuke、Blender、Unreal 这些专业创作软件。DCC CLI Gateway 就是个「让 AI 远程操控这些软件」的中枢——把「在软件里点一下」变成「Agent 发一条指令」，创作流程能串进自动化。

它能帮你干啥

  • 作为统一入口，让 AI / 无头 CLI 宿主直接控制正在运行的 DCC 软件；
  • 覆盖 Nuke、Blender、3ds Max、Unreal、ZBrush、Houdini 等专业软件；
  • 把软件操作变成可编排的指令，接进 CI / 流水线自动跑。

3 步上手（概念）

  1. 本机装好某款 DCC 软件，并接入 DCC-MCP 协议；
  2. 让 Agent 通过本网关发指令驱动软件；
  3. 把「渲染 / 批处理 / 资产操作」编进自动化流程。

常见坑

  • 它不是 WorkBuddy 内置能力，是 DCC-MCP 生态的「运行中枢」；
  • 真正用起来需要本机装有对应 DCC 软件并接入协议；
  • 它是基础设施层，更多是「让别的技能/脚本能控软件」，不是直接出图。

进阶版 · 玩出花

它在生态里的位置

DCC-MCP 是一套「让 Agent 控制专业创作软件」的协议。这套生态里有三个配套技能，各管一段：

  • dcc-cli-gateway（本技能）——运行中枢，Agent 借它发指令控制实时软件；
  • dcc-mcp-creator——教开发者和 Agent 为某款 DCC 软件新建 / 现代化一个适配器（adapter）；
  • dcc-mcp-skills-creator——为 dcc-mcp-core 生态创建 / 校验 / 脚手架 / 评审 DCC-MCP 技能（写 SKILL.md、tools.yaml、scripts）。

适用场景

  • 视频 / 3D / VFX 自动化生产：批量渲染、批处理资产；
  • CI 里跑创作任务：提交即触发渲染/导出；
  • Agent 直接操作专业软件完成创意任务，少点鼠标。

配「视频创作」一起用

  • 配 media-use：软件里产出的素材，交给 media-use 补齐 BGM/音效/调色；
  • 配 Motu 人像调色：DCC 出的人像，再走 Motu 精修；
  • 配 Illo：概念插画先定调，DCC 里做三维落地。

边界与注意

它是「控制中枢」而非「生图器」，价值在于把专业软件接进 Agent 工作流。需要本机有对应软件 + DCC-MCP 接入才能跑；具体命令与适配器细节需以官方仓库/文档为准（本次未能拉取全文）。
