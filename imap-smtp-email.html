邮件收发

imap-smtp-email
分类：办公协作 即装即用（需配邮箱信息） 人群：小白向

小白版 · 3 分钟上手

一句话它是啥

一个藏在 WorkBuddy 里的「邮件总管」——你不用开浏览器、不用切客户端，直接说「帮我看下新邮件」「给张三发个带附件的报价单」，它就通过 IMAP 收、SMTP 发，任意邮箱通吃（Gmail / Outlook / 163 / QQ / 企业邮都行）。

它能帮你干啥

  • 收：检查未读、按发件人 / 主题 / 时间搜索、读正文、下载附件，不用开网页邮箱；
  • 发：一句话群发周报、带 PDF 附件发合同、HTML 排版发好看的新产品简报；
  • 多账号：工作号、个人号、163/QQ/Gmail/Outlook 全装一个配置里，`--account` 一键切换；
  • 场景：把「收发邮件」塞进自动化流水线（比如抓到客户询价邮件自动回模板）。

3 步上手

  1. 先告诉我你的邮箱类型（Gmail / 163 / QQ / 企业邮），我跟你说要填哪几个参数（主机 / 端口 / 账号 / 密码）；
  2. 关键一步拿「专用密码」：Gmail 去 myaccount.google.com/apppasswords 生成 16 位应用专用密码（普通登录密码 IMAP 不认）；163/QQ 要用「授权码」而非登录密码；
  3. 配置好后直接说人话：「查下今天未读邮件」「给 a@b.com 发个会议通知，附件是 agenda.pdf」。

常见坑

  • 用错密码：Gmail / 163 的「登录密码」会被拒，必须用应用专用密码 / 授权码——这是最容易卡的点；
  • 配置存哪：写在 ~/.config/imap-smtp-email/.env（权限 600，只有你能读），更新 skill 不会丢；
  • 没开 IMAP 服务：部分邮箱网页端要手动开启「IMAP/SMTP 服务」才能连，否则连不上。

进阶版 · 玩出花

进阶配置

底层是 Node 脚本 scripts/imap.js（收）和 scripts/smtp.js（发），跟我说「配邮箱」我帮你写进 .env；一份 .env 支持多账号：每个额外账号用大写前缀（如 WORK_IMAP_HOST），调用加 --account work；安全白名单 ALLOWED_READ_DIRS / ALLOWED_WRITE_DIRS 限制脚本能读写的目录，防越权。

与其他工具组合

  • 配「去 AI 味」：邮件正文先润色再发，客户读着不机械；
  • 配「长文写作 / PPT」：把邮件里的需求 / 反馈当素材，直接产出方案或汇报；
  • 配「腾讯新闻 / 定时任务」：每天把要闻 + 未读摘要拼成一封晨报自动发你。

自动化玩法

接定时任务：每天早 9 点自动 check 未读，有急件就汇总发你；触发器：收到含「报价 / 合同」的邮件自动 download 附件存到指定目录。

边界与注意

密码明文存 .env，但权限锁 600 且只在本地——别把 .env 提交进 GitHub（我们已经设了仓库，注意别误传）；自签证书邮箱服务器：把 IMAP_REJECT_UNAUTHORIZED / SMTP_REJECT_UNAUTHORIZED 设 false 放行；多账号名只能字母数字，区分大小写但 .env 里前缀统一大写。
