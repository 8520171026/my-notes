ElevenLabs 配音配乐

elevenlabs
分类：设计创作（视频） 需 API Key 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

一个“给视频做声音”的工具箱——文字变语音配音、生成音效和背景音乐、还能克隆你的专属声音。视频创作里旁白、BGM、角色音色一把抓。

它能帮你干啥

  • 把稿子念出来（文本转语音），多语种旁白都行；
  • 生成音效（爆炸、whoosh）和整段 BGM；
  • 列出现有声音、查配额余额；
  • 用几段样本克隆一个专属声音（播客/角色通用）。

3 步上手

  1. 准备 ElevenLabs API Key，设为 ELEVENLABS_API_KEY；
  2. 装好 python3 + ffmpeg；
  3. 一句“用 elevenlabs 给我这段稿子配音”就出 mp3。

常见坑

  • 要 API Key（付费额度，注意配额）；
  • 声音克隆只认指定样本目录，别乱指路径；
  • 中文旁白用 multilingual v2 更稳，情绪演绎用 v3 + 音频标签。

进阶版 · 玩出花

模型怎么选

模型特点适合
Eleven v3支持 [laughs] [excited] 等音频标签讲故事/角色/有情绪的旁白
Multilingual v2稳定多语种，无标签直白旁白、外语配音
Turbo v2.5低延迟实时/对话、非英语
Flash v2.5最快最便宜批量、占位音

常用命令

speech.py "Hello" -v <voice_id> -o out.mp3（配音）
sfx.py "Cinematic boom" -o boom.mp3（音效）
music.py --prompt "Soft ambient pad" --length-ms 30000 -o bed.mp3（配乐）
voiceclone.py --name "MyVoice" --files a.mp3 b.mp3（克隆）
quota.py --usage --days 7（查配额）

与其他工具组合

  • 配「mlx-whisper」：原片语音转字幕 + ElevenLabs 重新配音，做双语/换语种视频；
  • 配「DCC 创作中枢 / Nuke」：配音轨道直接进专业剪辑；
  • 配「PPT 演示文稿」：给幻灯片加 AI 旁白导出讲解视频。

边界与注意

需 ElevenLabs 付费额度与 Key；声音克隆涉及肖像/声音权，商用先确认授权；输出格式多，交付前选对码率（如 opus_48000_192 适合 AirPlay）。

多平台衍生钩子

  • 长文标题：《一条命令给视频配上人声：ElevenLabs 配音实战》
  • PPT 大纲（5 页）：封面 → 视频为什么需要好声音 → 4 类声音产出 → 克隆专属音色 → 行动号召
  • 短视频钩子（15s）：「文字直接变配音？让你的视频开口说话。」
