MoltGuard·Agent 安全守卫

moltguard
分类：偏门神器 OpenClaw 专属 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

给 AI Agent 套一层安全护栏，挡提示注入、防数据泄露、拦恶意命令（基于 OpenGuardrails）。

它能帮你干啥

  • 读文件 / 网页时检测藏着的 prompt injection；
  • 拦截外泄敏感数据；
  • 每天 500 次免费检测。

3 步上手（OpenClaw 平台）

  1. openclaw plugins install @openguardrails/moltguard；
  2. 装完立即测试读样本注入邮件看它报警；
  3. 用 /og_status 看配额与防护模式。

常见坑

  • 这是 OpenClaw 平台专属插件；
  • WorkBuddy 用户请用内置的「AgentGuard」（同属偏门安全类，已收录）。

进阶版 · 玩出花

进阶配置

/og_core 开管理台管账单 / 升级；/og_claim 把 Agent 认领到账号拿 API Key。

与其他工具组合

  • 与任何会读外部文件 / 网页的 Agent 配合，做输入侧安全兜底。

自动化玩法

每日巡逻式检测，出 5 维健康报告。

边界与注意

仅在 OpenClaw 生态生效；WorkBuddy 侧等同能力看 AgentGuard。
