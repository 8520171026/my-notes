HyperFrames Creative · 视频创意导演

hyperframes-creative
分类：设计创作 需 hyperframes CLI 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

想做视频，但不知道「配色咋定、字体咋选、旁白咋写、节奏咋排」？HyperFrames Creative 就是你的「视频创意导演」——专门管品牌调性、节奏、风格、旁白和构图，把方向定好，技术活交给别的模块。

它能帮你干啥

  • 给视频定调色板和配色，不再胡乱配色；
  • 选字体与排版，标题卡、字幕看起来专业；
  • 写旁白脚本：开场钩子、语气、数字念法都安排；
  • 规划分镜节奏（beat），一段段怎么切更顺；
  • 按「数据可视化 / 画中画 / 标题卡」等套路给构图方案。

3 步上手

  1. 先有技术底（hyperframes-core 的合约）；
  2. 对它说风格需求：「科技风、冷色调、快节奏开场」；
  3. 它吐出设计稿 / 分镜方向，你照着做视频。

常见坑

  • 它是“非动画”方向层，动效细节要交给 hyperframes-animation；
  • 依赖 HyperFrames 框架，不是 WorkBuddy 内置能力；
  • 别一上来就读完所有参考文档，按任务挑对应的读。

进阶版 · 玩出花

工作流：先读 spec，再定方向

如果项目已有 frame.md / design.md 设计稿，先读它——里面的 frontmatter（颜色、字体、间距、语气、约束）就是品牌真理。没有就按需求选路由：现成 frame 预设、命名风格、快速默认、或交互式选择器。

路由表（按话题查参考）

  • 配色 / 排版 / 偷懒默认值 → house-style.md；
  • 命名风格预设、情绪映射 → visual-styles.md；
  • 构图套路（画中画、标题卡、幻灯片）→ composition-patterns.md；
  • 数据 / 信息图呈现 → data-in-motion.md；
  • 分镜节奏 / 转场时机 → beat-direction.md；
  • 旁白脚本：钩子语言、价值前置 → narration.md / storyline.md；
  • 音频驱动视觉（按频段动）→ audio-reactive.md。

脚本工具

  • scripts/contrast-report.mjs — 检查渲染帧的对比度告警；
  • scripts/extract-audio-data.py — 预提取音频频段给音频驱动构图；
  • scripts/package-loader.mjs — 内置创意工具支撑脚本。

配「media-use」一起用

  • 先由本 skill 定视觉/叙事方向，再让 media-use 把 BGM/图标/logo/配音补齐，视频一条龙；
  • 配「PPT 演示文稿」：把分镜方向直接转成可编辑幻灯片提案；
  • 配「去 AI 味」：旁白脚本先去味，口播不机械。

边界与注意

不能推翻 hyperframes-core 的技术规则；极简技术稿不必强套设计系统；没让加的场景/旁白/音乐/字幕/转场别自作主张加。它是 HyperFrames 框架的创意方向 skill（MIT-0 许可），作为参考/展示型 skill 收录。

多平台衍生钩子

  • 长文标题：《不会配色排版旁白？一个视频创意导演 Agent 把方向全定好》
  • PPT 大纲（5 页）：封面 → 视频创意为啥重要 → 4 类方向能力 → 与 media-use 组合 → 行动号召
  • 短视频钩子（15s）：「做视频不知道配啥色、写啥旁白？这个创意导演 Agent 帮你定方向。」
