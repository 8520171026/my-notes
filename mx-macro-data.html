偏门神器 · 进阶向

东方财富宏观数据库

mx-macro-data
分类：偏门神器 需 EM Key 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

用大白话问宏观数据——「中国过去五年 M2 增速」「美国制造业 PMI」——它从东方财富库拽数，还顺手给你 CSV 和说明 txt。

它能帮你干啥

  • 国民经济核算 / 价格指数 / 货币金融 / 财政 / 外贸 / 就业 / 产业运行等多领域；
  • 返回 JSON → 自动转 CSV + 描述文件。

3 步上手

  1. 申请东方财富妙想 EM_API_KEY 并设为环境变量；
  2. 说「查询 中国 GDP 同比增速、CPI 同比」；
  3. 拿生成的 CSV。

常见坑

  • 必须说具体指标名（GDP / CPI / PMI…），不能说「中国经济」这种模糊词；
  • 地域可宏观（中国 / 美国 / 欧元区）。

进阶版 · 玩出花

进阶配置

支持相对时间（今年 / 过去三年 / 上月）和宏观地域（华东 / 中国各省），不用拆省市。

与其他工具组合

  • 配「valuation-analysis」把宏观变量喂进估值；
  • 配「文件整理器」管导出的 CSV 文库。

自动化玩法

定时拉一组关键宏观指标，生成监测面板。

边界与注意

密钥别硬编码 / 明文暴露；指标要具体，大类商品（稀土 / 农产品）要拆成具体品种。

多平台衍生钩子

  • 长文标题：《用大白话查宏观数据：GDP、CPI、M2 一句话拽出来》
  • PPT 大纲（5 页）：封面 → 宏观数据库能干啥 → 查询约束 → 组合玩法 → 行动号召
  • 短视频钩子（15s）：「写报告要宏观数据？说句人话它就给你 CSV 和说明。」
