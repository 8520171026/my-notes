Email 邮件自动化

email-automation
分类：办公协作 需邮箱授权 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

一个“让 AI 帮你管邮箱”的工具——自动分拣、归类、草拟回复、清掉订阅和通知，把收件箱清零。支持 Gmail / Outlook / IMAP，不用手工一封封看。

它能帮你干啥

  • AI 分析 incoming 邮件，按紧急度排优先级；
  • 自动把邮件分进自定义分类（紧急/重要/订阅/通知/收据）；
  • 给未读重要邮件草拟回复草稿，你只管看和发；
  • 7 天前的订阅、3 天前的通知自动归档；
  • 每天给你一份“省了多少时间”的收件箱报告。

3 步上手

  1. 配好邮箱（Gmail 最简单：开 Gmail API 拿 credentials.json）；
  2. 用大白话吩咐：“处理我的收件箱并归类”；
  3. 它跑完给你摘要+回复草稿，你点一下就发。

常见坑

  • 首次要授权邮箱，涉及账号安全，授权范围看清楚；
  • 自动归档不可逆，前一周先人工复核训练 AI；
  • 用应用专用密码（app password）比普通密码安全。

进阶版 · 玩出花

配置（环境变量）

EMAIL_PROVIDER（gmail/outlook/imap）、EMAIL_ADDRESS（必填）、GMAIL_CREDENTIALS_FILE、OUTLOOK_ACCESS_TOKEN、IMAP_SERVER/USERNAME/PASSWORD、AUTO_ARCHIVE、CATEGORIES 等。Gmail 走 API 最稳，Outlook 需 Azure 注册应用拿 Graph token。

自定义规则（rules.yml）

可按发件人 / 关键词设动作：boss 来信→标 urgent；含“ASAP”→标 urgent；订阅号→7 天归档；发票→打标签归档；带退订头→建议退订。

与其他工具组合

  • 配「语雀文档同步」：重要邮件一键归档成知识库条目；
  • 配「去 AI 味」：AI 草拟的回复更有你本人味；
  • 配「n8n 工作流」：邮件触发跨系统自动化。

边界与注意

要邮箱授权，企业账号可能受限；自动归档有风险，关键动作加确认；敏感邮件注意合规与隐私。

多平台衍生钩子

  • 长文标题：《收件箱清零术：让 AI 替你分拣、归类、回邮件》
  • PPT 大纲（5 页）：封面 → 邮件为什么越堆越多 → AI 分拣三板斧 → 3 个真实省时场景 → 行动号召
  • 短视频钩子（15s）：「每天 47 封邮件？让 AI 3 分钟帮你清零。」
