FreeRide 免费 AI 模型管家

free-ride
分类：元工具 需 OpenRouter Key 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

一个“白嫖 AI”管理器——自动把 OpenRouter 上的免费模型排好序、设好兜底，断一个自动切下一个，让你几乎零成本用上大模型。

它能帮你干啥

  • 想用 Claude/GPT/Qwen 但不想掏订阅费，全走免费模型；
  • 主模型被限流时自动切到兜底模型，对话不中断；
  • 给自己的 Agent 配一整套“免费模型池”；
  • 长期挂机的 Agent，配个守护进程自动从限流死锁里恢复。

3 步上手

  1. 去 openrouter.ai/keys 免费领一个 API Key 并设好环境变量；
  2. 装好 freeride 命令行；
  3. 说一句「帮我配免费 AI」，它自动排好主模型+兜底并重启网关。

常见坑

  • 必须先有 OpenRouter 免费 Key，否则命令直接报错；
  • 它改的是 OpenClaw 的配置文件（~/.openclaw/openclaw.json），只在 OpenClaw 环境生效；
  • 改完配置记得重启网关，否则不生效。

进阶版 · 玩出花

进阶配置

通过 freeride auto 把质量最高的免费模型设为主、按质量排好兜底链；freeride switch <模型> 指定具体模型；freeride rotate 在整条链都被限流时现场测活重建。还有个后台守护进程每 60 秒探一次，挂机必备。

与其他工具组合

  • 配「n8n 工作流」：把“免费模型调度”嵌进自动化流程；
  • 配「clawdhub」：免费模型不够用时，去技能市场搜更合适的技能补位。

自动化玩法

freeride-watcher 后台守护进程，主模型挂了自动重建兜底链，适合无人值守的长期 Agent。

边界与注意

免费模型有速率上限，高并发会被限流——兜底链就是为此存在；它只动 openclaw.json 里模型相关几个键，不碰别的配置；正式生产环境别只靠免费模型。
