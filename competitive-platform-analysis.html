竞品平台分析

competitive-platform-analysis
分类：竞品/平台对标 即装即用 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

选平台、写竞品报告、做对标分析的结构化框架。

啥时候用它

选平台、写竞品报告、做对标分析时。

它能帮你干啥

  • 客户定位简报（先建）
  • 筛选标准 + 玩家分类轴
  • 竞品分层 + 数据源取证
  • 评分矩阵模板 + 输出格式

常见坑

  • 别把它当万能生成器——它给的是结构化工作流，不是一键答案；
  • 无
  • 关键产出过质量门（Quality Gate）才交付，别跳过。

进阶版 · 玩出花

核心工作流

  1. 先建客户定位简报
  2. 列筛选轴、填玩家分类
  3. 打竞品分层、数据源取证
  4. 评分矩阵 → 产出报告

质量门怎么过

  • 每个判断要有数据源支撑
  • 避免主观臆断、避免功能列表堆砌

边界与注意

无 它是方法论技能，越具体的输入产出越准；跨平台/跨项目复用同一套框架即可。

多平台衍生钩子

  • 长文标题：《竞品分析别再堆功能列表：用分层法》
  • PPT 大纲（5 页）：封面 → 定位简报 → 筛选轴 → 玩家分层 → 评分矩阵 → 报告
  • 短视频钩子（15s）：「竞品分析只会列功能？用分层法让老板一眼看懂。」
