Drawio 架构图生成器

drawio-pro-skill
分类：开发工具 需 draw.io 桌面端 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

一个“用自然语言生成架构图/流程图并导出图片”的工具——描述你想要什么图，它生成 .drawio 文件并导出成 PNG/SVG/PDF。

它能帮你干啥

  • 架构图、流程图、ER 图、UML（时序/类图）；
  • SysML/MBSE、BPMN 业务流程、泳道图；
  • 网络拓扑、云架构（从 Terraform/K8s 生成）；
  • ML/DL 模型图（Transformer/CNN/LSTM）、思维导图。

3 步上手

  1. 本机装好 draw.io 桌面端；
  2. 用自然语言描述要画的图（如“画一个三层架构：前端/服务/数据库”）；
  3. 它生成 .drawio 并导出成图片给你。

常见坑

  • 必须本机有 draw.io 桌面端，纯无头/服务器环境跑不了导出；
  • 想要自动布局还得装 Graphviz（dot）；
  • 超复杂图形建议先口述大框架，再手动细修。

进阶版 · 玩出花

进阶配置

基于 draw.io 桌面 CLI 生成 .drawio XML 并本地导出。支持自定义样式、丰富图形库、泳道；可选自动布局依赖 Graphviz。

与其他工具组合

  • 配文档类 skill：把架构图直接嵌进技术文档/README；
  • 与 mermaid / excalidraw / plantuml 互补，按场景选；
  • 配代码仓库 skill：边读代码边出架构图。

自动化玩法

从 Terraform 或 K8s manifest 自动生成云架构拓扑图，基础设施变更同步出图。

边界与注意

导出依赖本机 draw.io CLI，CI/无头环境需预装；需要视觉核对的自检步骤在无视觉模型时会被跳过。
