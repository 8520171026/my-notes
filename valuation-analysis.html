偏门神器 · 进阶向

A股港股价值投资分析

valuation-analysis
分类：偏门神器 需 pdf-parser 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

用《股市真规则》（晨星 Pat Dorsey）方法论，把一只股票拆成护城河 / 财务 / 管理层 / 估值，给你一份像样的基本面分析。

它能帮你干啥

  • 护城河分析；
  • 财务健康检查；
  • DCF 估值；
  • 管理层评估、行业结构、投资决策整合。

3 步上手

  1. 装依赖技能 pdf-parser（抽财报 PDF 数据）；
  2. 说「分析 XX 股票的投资价值」；
  3. 它按框架出结构化报告。

常见坑

  • 分析结果仅供参考、不构成投资建议；
  • 依赖 pdf-parser 才能读财报；
  • 非商业用途。

进阶版 · 玩出花

进阶配置

基于模块化框架（护城河 / 财务 / 管理层三支柱汇到投资决策整合），可单模块深挖。

与其他工具组合

  • 配「腾讯自选股 / 同花顺」拿实时行情喂进去；
  • 配「去 AI 味」把报告改成你能发的研究笔记。

自动化玩法

建股票池，定期跑框架更新每只的护城河 / 估值状态。

边界与注意

框架偏价值投资，成长股 / 题材股不完全适用；自己判断风险。

多平台衍生钩子

  • 长文标题：《用晨星方法论拆一只股票：护城河到 DCF 估值一本账》
  • PPT 大纲（5 页）：封面 → 价值投资框架 → 模块拆解 → 组合玩法 → 行动号召
  • 短视频钩子（15s）：「想认真分析一只股票？让它按护城河+财务+估值给你出报告。」
