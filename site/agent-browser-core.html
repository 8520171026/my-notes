网页自动化

agent-browser-core
分类：开发提效 即装即用 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

一个"让 AI 替你操作浏览器"的能力——你用大白话下指令，它背后调 agent-browser 这个命令行工具，帮你打开网页、填表单、点按钮、截图、抓数据，全程不用你手动点点点。

它能帮你干啥

  • 自动填表提交：把信息批量填进网页表单、点提交，省掉重复手工；
  • 批量抓网页数据：把页面里的价格、标题、列表抓下来整理成表格；
  • 网页截图存档：把某个页面长图截下，或把看板 / 报表固定留存；
  • 自动化巡检：定时打开后台，看关键数据有没有异常；
  • 登录后操作：复用你的登录状态，去跑需要登录才能看的内容。

3 步上手

  1. 跟我说「用浏览器打开 XX 网站，把第一屏截个图」——我背后起一个浏览器实例；
  2. 接着说你要它干嘛，比如「把搜索框填上『AI 工具』然后回车」「把列表前 10 条抓出来」；
  3. 我返回结果（截图 / 抓到的数据 / 操作后状态），复杂任务会分步跟你汇报每一步。

常见坑

  • 默认不共享你的登录态：每次开的是独立浏览器，你在自己 Chrome 登着的账号它看不到，要复用得带 --user-data-dir；
  • 遇到验证码 / 复杂登录会交还给你：碰到 Cloudflare、OAuth 这类关卡会停下来让你手动过，而不是死循环重试；
  • 不是所有网站都能爬：反爬严的站点会触发风控，操作节奏要像人，别一秒点十下。

进阶版 · 玩出花

进阶配置

底层是 agent-browser CLI（Rust 实现，带 Node.js 兜底）。核心心法是三板斧：先快照（snapshot）→ 靠 refs 精准操作 → 操作后再次快照验证 DOM 真的变了。支持 --json 输出，方便脚本解析和流水线串接；操作前用 waits / load-state 检查页面是否就绪。

与其他工具组合

  • 配「腾讯新闻 / 任意网页抓取」：自动采到数据，再丢进知识库或表格；
  • 配「邮件收发」：爬到的日报 / 监控结果，自动发邮件汇报给你或团队；
  • 配「PPT 演示文稿」：把自动化跑出来的截图直接塞进汇报幻灯片；
  • 配「长文写作」：抓来的素材一键变成带出处的内容初稿。

自动化玩法

复杂任务先出计划再分步执行：批量下载、多页抓取、复杂表单这类，先给你看清晰步骤，再一步步跑并回禀每步结果；控制操作间隔、模拟人类输入速度，避开反爬机制；写操作后必须重新 snapshot 或用 get 确认页面状态真的变了——严禁"假完成"。

边界与注意

安全模式默认收紧：不随便用 eval、--allow-file-access、自定义 --executable-path、任意 --args；不轻易动网络路由、凭证、cookie；只允许目标域名白名单，默认阻断 localhost 和内网地址；敏感操作（输密码、批量下载、删数据）前一定先问你；令牌、账号密码当秘密，绝不外泄、不落明文日志。
