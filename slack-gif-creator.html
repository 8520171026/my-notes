Slack GIF 生成器

slack-gif-creator
分类：偏门神器 即装即用 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

一个「为 Slack 造优化动图」的工具箱——专门对付 Slack 的尺寸硬限制：消息 GIF（≤2MB / 480×480）和 emoji GIF（≤64KB / 128×128），自带尺寸校验，做出来就能直接传。

它能帮你干啥

  • 聊天里发会跳动的 emoji 表情动画；
  • 做一条消息动图活跃团队气氛；
  • 把团队梗图、庆祝动效变成可发的 GIF。

3 步上手

  1. 说「做个 Slack GIF：🔥 跳动一下」；
  2. 它用动画原语拼出帧、边做边校验尺寸；
  3. 达标就给你文件，直接传 Slack。

常见坑

  • emoji GIF 的 64KB 极严——控 10-15 帧、32-48 色、避开渐变；
  • 常跑尺寸校验，别等传不上去才发现问题；
  • 文字要加描边才在小图里看得清。

进阶版 · 玩出花

动画原语自由组合

shake / bounce / spin / pulse / fade / zoom / explode / wiggle / slide / flip / morph / move / kaleidoscope——像搭积木一样拼，做出 bounce+shake 的撞击感、move+shake 的触发感。

工程化细节

  • 校验器 check_slack_size / validate_dimensions 一键把关；
  • 调色板、文字描边、粒子特效、缓动函数（ease / bounce / elastic）随便调；
  • 依赖 pillow、imageio、numpy（缺了会自动装）。

与其他工具组合

  • 配「去 AI 味」：给 GIF 写有人味的文案；
  • 配「文件整理器」：把做好的动图按项目归档；
  • 配「Canvas 艺术海报设计」：静态主视觉 + 动态表情互补。
