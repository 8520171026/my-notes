media-use · Agent 媒体操作系统

media-use
分类：设计创作 需 HeyGen CLI 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

做视频时最头疼的就是「配乐哪来、音效哪来、图标去哪找、品牌 logo 怎么才正版」——media-use 就是给视频项目当“媒体采购部”：一句话说要啥，它帮你把 BGM、音效、图片、图标、品牌 logo、配音、调色块全找齐。

它能帮你干啥

  • 找背景音乐（BGM，1 万+ 曲库）和音效（SFX）；
  • 找图片 / 背景（7.5 万+ 矢量素材）和图标；
  • 正规渠道挖品牌 logo（svgl → simple-icons → 官方头像 → 域名 favicon 层层兜底）；
  • 生成配音（TTS 语音）；
  • 产出可直接粘贴的调色块和滤镜 LUT。

3 步上手

  1. 先装好 HeyGen 命令行（下面进阶版有命令）；
  2. 对它说：「给这段视频配个轻快的背景音乐 + 一个科技感 logo」；
  3. 它返回一行：resolved xxx → 路径 (类型, 信息)，直接拿去用。

常见坑

  • 它不是 WorkBuddy 内置能力，依赖外部 HeyGen CLI（免费 OAuth 通道）；
  • 首次要 OAuth 登录 HeyGen，会送免费额度，但企业素材注意版权；
  • 重复相同的素材请求会自动复用，省额度。

进阶版 · 玩出花

核心机制：resolve 一条龙

media-use 定位是 HyperFrames 生态的「媒体 OS」——HyperFrames 负责播放，media-use 负责其余所有媒体资源。它把 8 类缺口（缺图/缺标/缺配音/缺剪辑/缺字幕驱动剪辑/缺跨项目记忆/缺调色/缺生成）统一成一条 resolve 命令：

  • --type bgm|sfx → HeyGen 音频目录（10k+ 曲库 / 19 个内置音效）；
  • --type image|icon → HeyGen 素材搜索（75k+ 矢量）；
  • --type logo → svgl → simple-icons → GitHub 组织头像 → 域名 favicon 四级兜底；
  • --type voice → HeyGen TTS 免费通道，可选本地 Kokoro；
  • --type grade|lut → 吐出可直接粘贴的调色块 / 冻结 .cube 滤镜文件。

安装与授权（免费通道）

所有外部工具自带鉴权，本 skill 不存任何密钥。生成能力围绕 HeyGen CLI 的免费 OAuth 路径：

curl -fsSL https://static.heygen.ai/cli/install.sh | bash
heygen update && heygen auth login --oauth

装完跑 node scripts/resolve.mjs --doctor 自检。

配「HyperFrames 创作」一起用

  • 配 hyperframes-creative：先定视觉/叙事方向，再让 media-use 把素材补齐，视频一条龙；
  • 配「去 AI 味」：配音文案先去味，声音更自然；
  • 复用机制：--candidates 列可复用资源，--reuse <sha> 导入全局缓存资产，跨项目省额度。

边界与注意

Run 它需要你本机装好并登录 heygen；转录默认 Parakeet（比 whisper.cpp 更快更准），去背交给 hyperframes CLI。敏感/商用素材注意授权与合规。
