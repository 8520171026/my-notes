偏门神器 · 音乐向

Music 个人音乐库

music
分类：偏门神器 即装即用 人群：乐迷 / 通用

小白版 · 3 分钟上手

一句话它是啥

一个私人音乐管理系统——把你的发现、收藏、演出、听歌记忆全记下来，需要时它自动从你的库里调出来。

它能帮你干啥

  • 发现清单：听到想听的直接存，带「谁推荐/哪来的」上下文；
  • 收藏管理：歌 / 专辑 / 艺人分门别类，含「当下循环」；
  • 场景歌单：运动 / 专注 / 公路 trip，且注明「为啥这些管用」；
  • 演出追踪 + 实体收藏 + 音乐记忆：演唱会、黑胶、按年份的情绪原声。

3 步上手

  1. 随口说一首歌 / 专辑；
  2. 它帮你存（带上下文），建好 ~/music/ 工作区；
  3. 下次问「听点啥」，它先查你的库再推荐。

常见坑

  • 它不假设接流媒体，就是本地 markdown 库；
  • 别硬塞对方不爱的风格，简单列表就够；
  • 它会在对的时间主动提醒（「你 3 个月前存了那张碟还没听」）。

进阶版 · 玩出花

进阶配置

目录结构清晰：discover / favorites / playlists / concerts / collection / memories。它会做艺人深潜（按时间排唱片、标粉丝最爱、标必听曲）、按心情/活动调度（运动要高能量、专注要器乐、做饭要熟歌）。

与其他工具组合

  • 配「健康养生 Health」：运动歌单 / 专注歌单直接服务健康目标；
  • 配「自适应学习 Learning」：把「学乐器」这类目标做成进度系统；
  • 配「去 AI 味」：把推荐语写得更像你本人语气。

边界与注意

纯本地笔记系统，不替你听、不接平台 API；过组织反而弃用，保持轻量；它记的是「你和音乐的关系」而非曲库本身。

多平台衍生钩子

  • 长文标题：《别再让好歌沉进收藏夹：用 AI 搭一个会主动提醒你的私人音乐库》
  • PPT 大纲（5 页）：封面 → 为啥需要音乐管理 → 目录结构 → 场景歌单怎么用 → 主动提醒的巧思
  • 短视频钩子（15s）：「3 个月前存的那张碟还没听？它比你还记得。」
