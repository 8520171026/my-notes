偏门神器 · 进阶向

X/Twitter 搜索·xAI

x-search
分类：偏门神器 需 XAI Key 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

用 xAI 的 Grok 实时搜 X（Twitter）帖子——找热点、看大家在聊啥、做社媒舆情。

它能帮你干啥

  • 按关键词搜推文；
  • 按账号过滤（--handles）/ 排除（--exclude）；
  • 按日期范围；带图 / 视频理解。

3 步上手

  1. 去 console.x.ai 拿 XAI_API_KEY 设环境变量；
  2. python3 scripts/search.py "what is trending in AI"；
  3. 看带引用链接的结果。

常见坑

  • --handles 和 --exclude 不能同用；
  • 结果带原帖引用链接，记得标注来源。

进阶版 · 玩出花

进阶配置

--from/--to 限定日期；--images --video 开图文理解；Grok 负责搜 + 总结。

与其他工具组合

  • 配「去 AI 味」把搜来的素材写成社媒稿；
  • 配「内容营销」做热点追踪内容。

自动化玩法

定时搜某话题最新帖，汇总成舆情简报。

边界与注意

依赖 xAI 额度；引用他人内容注意版权与标注。

多平台衍生钩子

  • 长文标题：《用 Grok 实时搜 X：热点、舆情、社媒素材一把抓》
  • PPT 大纲（5 页）：封面 → X 搜索能干啥 → 过滤与日期 → 组合玩法 → 行动号召
  • 短视频钩子（15s）：「想看 X 上大家在聊啥？一句 Grok 搜索把热点端上来。」
