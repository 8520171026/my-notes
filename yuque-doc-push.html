语雀文档同步 · Yuque Doc Push

yuque-doc-push
分类：办公协作 需语雀 Token 人群：小白向

小白版 · 3 分钟上手

一句话它是啥

你写好的 Markdown 文档，想一键同步到语雀知识库？这个技能让 AI 帮你「把本地文章推到语雀、拉回来、查目录、改内容」——不用在网页里手动复制粘贴。

它能帮你干啥

  • 在语雀知识库里新建 / 更新 / 删除 / 读取文档；
  • 新建后自动挂到目录（TOC），不用手动排；
  • 双向同步：本地 Markdown ↔ 语雀，只推真正改动的部分；
  • 查看知识库的目录结构，心里有数。

3 步上手

  1. 准备语雀知识库 URL和API Token（语雀→头像→账号设置→Token→新建，给目标库读写权限）；
  2. 对它说「把这篇推到语雀」，它跑一次 setup 自动连上；
  3. 之后「同步一下」就搞定，它自己比对哪些变了。

常见坑

  • 它不是 WorkBuddy 内置能力，需要一个语雀 Token（你自己申请）；
  • Token 很私密——它绝不会在聊天里回显，只悄悄喂给本地脚本；
  • 同步只动「已发布版本」，队友在网页里没发布的草稿不会被覆盖。

进阶版 · 玩出花

核心：CRUD + 同步引擎

底层走语雀 OpenAPI，本技能只管「单个知识库内」的文档增删改查 + 目录管理，以及本地 Markdown 的双向同步。它不碰知识库/团队的创建删除、成员管理、跨库迁移——边界很清楚。

命令速查

创建python scripts/yuque_cli.py create -t "标题" -b "正文"
更新update <id_or_slug> -t "新标题"
删除delete <id_or_slug> --confirm（必须带 --confirm）
同步sync（只推改动）
拉取pull --slug <slug>

同步的聪明之处

sync 用 .yuque-sync.json 记录每个文档的本地内容哈希和远端版本号，没变的文档直接跳过，不浪费 API 调用。支持三种本地布局：flat（顶层 .md）、nested（子目录）、frontmatter（文件头带 slug）。推送时还会自动：剥掉 frontmatter、把本地 [文本](file.md) 链接改写成语雀 slug 链接、修好加粗标点。

配「腾讯乐享知识库」一起用

  • 语雀管对外文档 / 协作，乐享管内部问答知识库，两套互补；
  • 配「去 AI 味」：推到语雀前先把稿子去过味，读起来像人写的；
  • 配「文档转 Markdown」：别的格式先转 MD，再统一推语雀。

边界与注意

首次 setup 必须用户给 URL + Token；401 是 Token 失效要去重开；429 限流会短暂等待重试；绝不自动删远端文档——本地文件没了会停下来问你「删 / 拉回 / 忘掉」三选一。Token 永不进 git。
