CalDAV 日历同步器

caldav-calendar
分类：偏门神器 需装依赖 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

把 iCloud / Google / Fastmail / Nextcloud 等 CalDAV 日历同步到本地命令行，用 khal 查、用 vdirsyncer 同步，不用开网页日历。

它能帮你干啥

  • 看今天 / 本周 / 某日期范围的日程；
  • 按关键词搜索日程；
  • 命令行新建、删除日程；
  • 改完再同步回云端。

3 步上手

  1. 在 Linux 上装 vdirsyncer + khal；
  2. 配好你的 CalDAV 账号；
  3. vdirsyncer sync 同步、khal list 看日程。

常见坑

  • 仅支持 Linux（Win/Mac 需 WSL 或等价环境）；
  • 改完必须再 vdirsyncer sync 才推到云端；
  • 编辑用交互式 khal edit，自动化可用 tmux。

进阶版 · 玩出花

进阶配置

vdirsyncer 把多个云端日历拉成 local .ics，khal 负责读写。可脚本化做定时提醒与日报。

与其他工具组合

  • 配「Todoist / 日程类」做本地任务 + 日历联动；
  • 配「文件整理器」把导出的日程归档成知识。

自动化玩法

写个 cron 每天 vdirsyncer sync + 把今天日程发到飞书 / 邮件。

边界与注意

只支持 CalDAV 协议日历；多日历用 khal list -a Work 指定。
