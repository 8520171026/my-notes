Deep Research Gemini 自主研究

deep-research
分类：偏门神器 需 Gemini API Key 成本：$2-5/次

小白版 · 3 分钟上手

一句话它是啥

调 Google Gemini Deep Research Agent 跑“自主多步研究”——它会自己规划、搜索、阅读、综合，最后吐一份带引用的详细报告。耗时 2-10 分钟，单次花费约 $2-5。

它能帮你干啥

  • 市场分析、竞品盘点；
  • 技术文献综述（literature review）；
  • 技术调研、投资尽调（due diligence）；
  • 历史时间线、框架/产品/技术对比分析。

3 步上手

  1. 去 Google AI Studio 拿 Gemini Key，设成环境变量 GEMINI_API_KEY；
  2. 跑 python3 scripts/research.py --query "你的研究问题"；
  3. 用 --stream 看实时进度，或 --wait <id> 等结果，--continue 追问。

常见坑

  • 要 Python 3.8+ 和 httpx 库，先 pip install -r requirements.txt；
  • Key 是 GEMINI_API_KEY，不是别的名字；
  • 单次 $2-5，复杂任务更贵，先小问题试水。

进阶版 · 玩出花

输出格式与成本

默认人类可读 Markdown 报告；可加 --json 拿结构化数据供程序调用，--raw 拿未处理 API 响应。单次 token 约 250k-900k 输入 / 60k-80k 输出。

工作流编排

  • 用户提研究 → 跑 --query；
  • 先告知预估时长（2-10 分钟）；
  • --stream 或轮询 --status 监控；
  • 返回格式化结果，--continue 做追问延伸。

与其他工具组合

  • 配「写作研究 Content Research Writer」：报告引用直接喂进长文；
  • 配「递归研究 Recursive Research」：Deep Research 出初稿，递归深挖文献；
  • 配「内容营销」：调研结果变竞品分析/白皮书内容。

边界与注意

退出码 0=成功、1=错误（API/配置/超时）、130=用户 Ctrl+C 取消；报告引用需你最终核实，Agent 不替你背锅。
