Stock Market Pro 行情分析

stock-market-pro
分类：金融投资 即装即用（需 uv） 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

一个“本地优先的行情研究工具箱”——基于 Yahoo Finance，一句话拿实时报价、基本面，还能吐出高清技术指标图。

它能帮你干啥

  • 实时报价（价格+涨跌幅）；
  • 基本面速览（市值、前瞻 PE、EPS、ROE）；
  • 终端友好的 ASCII 趋势图；
  • 高清 PNG 指标图：RSI / MACD / 布林带 / VWAP / ATR；
  • 一键研报：文字摘要 + 图表路径。

3 步上手

  1. 装好 uv（astral-sh/uv）；
  2. 跑：uv run --script scripts/yf.py price AAPL 拿报价；
  3. 出图：uv run --script scripts/yf.py pro AAPL 6mo --rsi --macd。

常见坑

  • 覆盖美股/韩股/加密/外汇，不是 A 股；A 股要另接 akshare 等数据源；
  • 依赖 uv run --script，没装 uv 先装；
  • 雅虎数据偶有延迟/缺失，关键决策交叉验证。

进阶版 · 玩出花

进阶配置

全部走 uv run --script scripts/yf.py。子命令：price / fundamentals / history / pro / report / option。指标可选 --rsi --macd --bb --vwap --atr。

与其他工具组合

  • 配「深度投研」：行情图 + 研报形成完整研究；
  • 配「新闻搜索」：DDG 扫新闻做舆情；
  • 配「Blave Quant」：跨市场（美股+台股+加密）对照。

自动化玩法

批量对自选池出研报图，定时跑监控异动；期权/资金流可走浏览器优先（Unusual Whales）。

边界与注意

数据源自 yfinance，可用性随雅虎接口波动；仅作研究参考，不构成投资建议；A 股场景需自行接入国内数据源。
