ClawdHub 技能市场 CLI

clawdhub
分类：元工具 即装即用 人群：小白向 来源：clawhub.ai 第三方

小白版 · 3 分钟上手

一句话它是啥

一个命令行"技能商店"——从 clawhub.com 搜、装、更新、发布 AI 智能体技能。想即时抓新技能、同步到最新版、或把自己写的技能发上去，都靠它一条命令搞定。

它能帮你干啥

  • 搜索技能：clawdhub search "关键词" 找现成好货；
  • 安装技能：clawdhub install <技能名> 拉到本地 ./skills；
  • 更新同步：升到最新版或指定版本，update --all 一把全更；
  • 发布自己的技能：把你写的技能文件夹发到 clawhub.com 跟大家共享。

3 步上手

  1. 装 CLI：npm i -g clawdhub（需要 Node 环境）；
  2. 搜：clawdhub search "postgres backups"；
  3. 装：clawdhub install <技能名>，技能落到本地技能目录。

常见坑

  • 它是给 Clawdbot / OpenClaw 设计的，装出来的技能默认目录是 ./skills（可用 --dir 改）；
  • 发布要先 clawdhub login，牵扯 clawhub.com 账号；
  • 在 WorkBuddy 里我们已经手动把它的 SKILL.md 落到 ~/.workbuddy/skills/，无需依赖 CLI 也能识别。

进阶版 · 玩出花

进阶配置

安装可锁版本：clawdhub install my-skill --version 1.2.3。更新走 hash 比对 ＋ 升级：update my-skill、update --all --no-input --force。list 看已装清单。发布带上元数据：clawdhub publish ./my-skill --slug my-skill --name "My Skill" --version 1.2.0 --changelog "Fixes + docs"。

与其他工具组合

  • 配「Clawdbot 文档专家」：先用 clawddocs 查到好技能，再 clawdhub install 直接装，导航＋安装一条龙；
  • 配「创建 Skill」：本地写好自己的技能，用 clawdhub 一键发到市场共享。

自动化玩法

用 clawdhub update --all 定期把本地技能同步到最新；CI 里发布新版本也只需一行 publish。默认 registry 是 clawhub.com，可用环境变量 CLAWDHUB_REGISTRY 或 --registry 指向私有源。

边界与注意

全局装 npm 包会改动你的环境（我们这里没替你跑 npm i -g，需要时你自行决定）；登录 / 发布涉及第三方账号，注意凭证安全；它本质是"技能市场遥控器"，在 WorkBuddy 里主要当扩展能力的参考入口。
