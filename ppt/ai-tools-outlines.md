# 多平台衍生 · PPT 大纲（一份素材三处复用）

> 每个工具 5 页大纲，直接交给「PPT 演示文稿」skill 生成可编辑幻灯片。

---

## 1. PPT 演示文稿（pptx-generator）
1. 封面：一句话生成 PowerPoint
2. 痛点：熬夜排版、没模板、赶时间
3. 三个核心功能：11 种页面类型 / 5 套配色 / 图表表格时间线
4. 真实案例：从一句话到能交差的初稿
5. 行动号召：现在就对我说"帮我做个关于 XX 的 PPT"

## 2. 腾讯新闻（tencent-news）
1. 封面：天下事一袋装
2. 它能干啥：7×24 热榜 / 早晚报 / 实时资讯
3. 三步上手：装好 → 配 API Key → 说人话查
4. 进阶玩法：组合其他工具做每日简报
5. 行动号召：今天有什么重要新闻？

## 3. 邮件收发（imap-smtp-email）
1. 封面：任意邮箱收发信
2. 痛点：多客户端来回切、附件管理乱
3. 三步上手：配专用密码 → 说"发邮件给 XX" → 自动收发
4. 进阶玩法：自动发 newsletter 推送你的新工具
5. 行动号召：把你的邮箱接上来试试

## 4. 去 AI 味（humanizer）
1. 封面：别让你的文章被一眼看穿
2. 什么是"AI 味"：套话、三段式、破折号滥用……
3. 三个最露馅的套路：夸大意义 / 促销腔 / 模糊引用
4. 去味前后对比：一段文案改前改后
5. 行动号召：把稿子丢给我，说"去下 AI 味"
