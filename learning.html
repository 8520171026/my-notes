Learning 自适应学习

learning
分类：偏门神器 即装即用 人群：学生 / 终身学习者

小白版 · 3 分钟上手

一句话它是啥

一个自适应学习陪跑——自动摸清你「咋学最好」，把教学风格、格式、深度调成你的偏好，而不是一套讲法喂所有人。

它能帮你干啥

  • 检测哪种讲解对你管用、哪种不管用；
  • 覆盖所有学习场景（学术 / 职场 / 随便探索）；
  • 收到 2+ 一致信号后才确认偏好，不乱贴标签；
  • 用超紧凑的笔记记录你的学习画像。

3 步上手

  1. 它观察你咋学（你爱看图还是爱看代码、爱深还是爱浅）；
  2. 慢慢填好偏好（风格 / 格式 / 工具 / 别做啥）；
  3. 之后讲解自动适配，且会持续进化。

常见坑

  • 空段 = 还没偏好，先让它观察别急着定；
  • 它不替你学，是调「教法」不是替你吸收；
  • 偏好会变，允许它随你成长更新。

进阶版 · 玩出花

进阶配置

四个可调维度：Style（你咋吸收最快）、Format（爱啥格式：参考文档 / 对话 / 图示）、Tools（你爱的学法）、Never（对你不管用的）。配 dimensions.md / criteria.md 做分类与格式约束。

与其他工具组合

  • 配「健康养生 Health」：把健康知识按你的学习偏好讲；
  • 配「PDA 任务重构」：给神经多样性人群做更友好的教学语言；
  • 配「文案 / PPT」：把学到的东西落成你能复述的笔记。

边界与注意

它是「元技能」——管的是「怎么教你」而非「教啥」；需要你给它信号才能校准；别指望一次对话就完美，观察 2+ 次才定型是防误判。

多平台衍生钩子

  • 长文标题：《同一个知识点有人一看就懂有人死活不行：让 AI 先摸清你咋学》
  • PPT 大纲（5 页）：封面 → 学习风格差异 → 四维度画像 → 2+ 信号才定型 → 配健康/PDA 的巧用
  • 短视频钩子（15s）：「讲同一件事，它给你的版本和给别人的不一样——因为摸清了你怎么学。」
