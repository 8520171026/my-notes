偏门神器 · 小白向

买手·全网比价

taobao
分类：偏门神器 需 uv 人群：小白向

小白版 · 3 分钟上手

一句话它是啥

说一句「想买 XX」，它跨淘宝 / 天猫 / 京东 / 拼多多 / 抖音 / 快手等 10 个平台比出最优价和优惠券。

它能帮你干啥

  • 按关键词搜全网价；
  • 看某商品详情 + 购买链接 + 优惠券；
  • 挑最便宜的下单。

3 步上手

  1. 装好 uv；
  2. 说「帮我在全网比价 XX」；
  3. 它跑 uv run scripts/main.py search --source=0 --keyword='XX' 出结果。

常见坑

  • 脚本只当客户端请求三方比价站（maishou88.com）数据，不读写你本地文件，可放心；
  • 价格实时波动，以页面为准。

进阶版 · 玩出花

进阶配置

--source 指定平台（0 全部 / 1 淘宝天猫 / 2 京东 / 3 拼多多…）；detail --source= --id= 看详情购买链接。

与其他工具组合

  • 配「文件整理器」把比价结果存成采购清单；
  • 配「去 AI 味」写种草 / 测评文案。

自动化玩法

把常买清单做成定时比价，降价提醒。

边界与注意

比价数据来自第三方，下单前自己核对平台活动。

多平台衍生钩子

  • 长文标题：《下单前先比价：一句话跨 10 个平台找出最便宜的那件》
  • PPT 大纲（5 页）：封面 → 全网比价是啥 → 搜索与详情 → 组合玩法 → 行动号召
  • 短视频钩子（15s）：「想买 XX 又怕买贵？让它跨淘宝京东拼多多比个遍。」
