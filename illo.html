设计创作 · 编辑插画

Illo · 有性格的编辑插画

illo
分类：设计创作 需图像后端 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

写文章想配张图，但嫌通用生图器「没灵魂」？Illo 是专做编辑插画的——一个反复出现的吉祥物角色，在每个画面里把你的想法「演」出来，是有角色、有风格的系列插画，不是随便一张图。

它能帮你干啥

  • 给文章 / 帖子 / 通讯 / 链接配一张讲清概念的图（关键判断、流程、前后对比、陷阱、循环）；
  • 迷你漫画：2–4 格同框，讲一个分阶段的推进；
  • 解说图：把可追踪的结构（流水线、时间线、循环）画成手绘风示意图；
  • 角色抠图：透明背景的吉祥物 PNG，方便你后续叠加；
  • 还能造你自己的吉祥物、装社区角色、换风格。

3 步上手

  1. 对它说：「给『你是瓶颈』这篇文章配张图」；
  2. 它选好角色（默认 Blot 水墨滴）和风格，出图；
  3. 拿到 PNG，直接拖进文章 / 推文 / 幻灯片。

常见坑

  • 它不是通用生图器，只在该技能被点名时用，不搞「画个猫」那种随意图；
  • 出图需要本机有 python3 + 网络，并配好一个图像后端（下面进阶版讲）；
  • 风格是「配置化」的——角色包带着风格走，换角色才换风。

进阶版 · 玩出花

三种图像后端（按需选）

  • Codex 后端（Codex 订阅用户免费）：用你自己的 Codex CLI 额度，无 Key、无 Token；
  • Grok 后端（Grok 订阅用户免费）：用你的 Grok 额度，但 JPEG 无透明通道，做不了抠图；
  • OpenRouter 后端（付费，直连或兜底）：需要 OpenRouter API Key，可指定模型。

16 种内置风格

riso（默认，颗粒网点的油墨感）、blueprint、woodcut、pixel、clay、manila、chalk、phosphor、enamel、gouache、felt、diorama、sketchbook、bricks（乐高摄影风）、fizz、bloom。风格跟着角色包走——换角色包就换风格。

典型用法

每个命令都要在同一行内先 SKILL_DIR="<本技能目录>" 再调 illo.py（shell 状态不跨块保留）：

python3 "$SKILL_DIR/scripts/illo.py" doctor # 自检
python3 "$SKILL_DIR/scripts/illo.py" generate --prompt-file /tmp/shot.txt --ref "$SKILL_DIR/assets/character-reference.webp" --aspect 16:9 --out "assets/<slug>/01.png"

配「视频创作」一起用

  • 配 media-use：插画定稿后，用 media-use 把 BGM/音效补齐，做成带配图的短视频；
  • 配「PPT 演示文稿」：把系列插画直接拖进幻灯片，汇报更有记忆点；
  • 配「去 AI 味」：配图文章的文案先去味，图文一致不机械。

边界与注意

引擎只壳调你自己的订阅 CLI 或 OpenRouter Key，绝不读环境变量里的密钥、也不接命令行参数传密钥——Key 永远是你自己 init 写入的。每个画面只讲一个隐喻，绝不抄示例构图。Chat 会话里成品以原文件附件交付，避免平台压缩毁掉 riso 颗粒感。

多平台衍生钩子
