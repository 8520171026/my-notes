Clawdbot 文档专家

clawddocs
分类：办公协作 即装即用 人群：小白向 来源：clawhub.ai 第三方

小白版 · 3 分钟上手

一句话它是啥

一个"Clawdbot 文档导航员"——你问 Clawdbot 怎么配、哪里报错、某个功能是啥，它用一套决策树帮你精准定位到对应的官方文档页，还能跑搜索脚本、抓取具体文档、追踪版本变化。简单说：你不用自己翻文档海洋，它替你指路。

它能帮你干啥

  • 配置 Clawdbot：provider（Discord/Telegram/WhatsApp…）、网关、自动化、各平台安装；
  • 排查"为啥 X 不工作"——通用问题、provider 专属、浏览器工具类分别指路；
  • 搜文档、按关键词做全文检索，或拉取某一篇具体文档页；
  • 版本追踪：给文档拍快照，比对改动，升级不掉队。

3 步上手

  1. 把你的 Clawdbot 相关问题发给我（"网关怎么配""定时任务咋弄"都行）；
  2. 说一句「用 clawddocs 帮我查」；
  3. 我返回定位到的文档路径 ＋ 关键配置片段，你照着抄即可。

常见坑

  • 它只懂 Clawdbot 一家的文档，不是通用搜索引擎，别拿它查别的；
  • 全文索引依赖 qmd 先建索引（build-index.sh fetch → build）；
  • 前提是——你真在用 Clawdbot；在 WorkBuddy 里它主要当"参考资料"看。

进阶版 · 玩出花

进阶配置

核心是那张决策树：按"怎么搭 / 为啥挂 / 怎么配 / 是啥 / 怎么自动化 / 怎么装"把问题分流到 providers/、gateway/、concepts/、automation/、install/、platforms/ 等文档区。技能自带一组脚本（都在 ./scripts/）：

  • 核心：sitemap.sh 看全部分类、cache.sh status/refresh 管缓存；
  • 搜索发现：search.sh 关键词、recent.sh 7（近 N 天更新）、fetch-doc.sh 路径；
  • 全文索引：build-index.sh fetch/build/search "短语"；
  • 版本追踪：track-changes.sh snapshot 存档比对。

与其他工具组合

  • 配「ClawdHub 技能市场 CLI」：查到好技能，直接用 clawdhub install 装下来，导航＋安装一条龙；
  • 配「创建 Skill」：看懂 Clawdbot 文档后，照着给自己的智能体写技能。

边界与注意

它只服务于 Clawdbot 生态，离了这家就抓瞎；脚本依赖 bash ＋ 可选的 qmd 工具；在 WorkBuddy 里建议当"文档地图"参考，别指望它直接改你的 Clawdbot 实例。
