SQL 数据库工具箱

sql-toolkit
分类：偏门神器 即装即用 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

直接在命令行玩转关系型数据库（SQLite / PostgreSQL / MySQL），不用 ORM、不用开客户端。

它能帮你干啥

  • 设计表结构；
  • 写复杂查询（联表 / 聚合 / 窗口函数 / CTE）；
  • 做迁移、加索引、备份恢复、调慢查询。

3 步上手

  1. 零配置用 SQLite：sqlite3 mydb.sqlite "SELECT..."；
  2. CSV 直接导入；
  3. sqlite3 -csv ... > out.csv 导出。

常见坑

  • 生产库改结构前先备份；
  • 慢查询用 EXPLAIN + 索引优化；
  • MySQL / PG 需各自客户端。

进阶版 · 玩出花

进阶配置

SQLite 随 Python 自带，零安装即可原型；PG / MySQL 用对应命令行客户端；可写迁移脚本版本化管理 schema 变更。

与其他工具组合

  • 配「文件整理器」管数据库备份文件；
  • 配「Python 数据分析」做取数后分析。

自动化玩法

把备份 / 导出写成定时任务，版本化迁移脚本。

边界与注意

大库操作注意锁表；删数据不可逆，先 SELECT 确认。
