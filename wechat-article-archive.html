资讯收藏 · 小白友好

公众号文章归档器

wechat-article-archive
分类：资讯收藏 即装即用（需 python+node） 人群：小白友好

小白版 · 3 分钟上手

一句话它是啥

一个“公众号文章/小绿书一键存成本地 Markdown+图片”的工具——收藏、二次创作、建自己的素材库都好用。

它能帮你干啥

  • 保存公众号文章为正文 Markdown + 本地图片；
  • 提取文章里多张图片到 assets/；
  • 小绿书/图片笔记页整页归档；
  • 图片下到本地，不传任何云盘。

3 步上手

  1. 装依赖：npm install + python3 -m venv .venv && pip install -r requirements.txt；
  2. 跑：python scripts/archive_wechat_article.py "文章URL" "目标文件夹"；
  3. 看 JSON 报告：Markdown 路径、图片数、失败项。

常见坑

  • 微信可能临时限频（访问过于频繁），换网络/稍后再试；
  • 个别图片下不来会保留原链接，不影响正文；
  • 它只做本地归档，不会帮你发文/上传。

进阶版 · 玩出花

进阶配置

脚本参数：--filename 自定义文件名、--skip-images 仅要文字、--html-file 用浏览器另存的 HTML 恢复（直连被拦时）。

与其他工具组合

  • 配「语雀文档同步」：归档后一键推到知识库；
  • 配「Obsidian」：做笔记素材源；
  • 配「去 AI 味」：归档后二次创作更自然。

自动化玩法

对关注的一批公众号做定时批量抓取，沉淀成可检索的本地文库。

边界与注意

仅限本地归档，不用于上传/发消息；遵守微信平台条款，勿批量侵权搬运。

多平台衍生钩子

  • 长文标题：《好文章别只收藏：一键把公众号存成本地 Markdown》
  • PPT 大纲（5 页）：封面 → 收藏的痛 → 归档器怎么用 → 3 个场景 → 行动号召
  • 短视频钩子（15s）：「刷到的好文章想留存？一条命令存成本地 Markdown 还不传云。」
