公众号文章爬虫

wechat-article-spider
分类：偏门神器 需装依赖 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

贴一个公众号文章链接，自动把正文抓成 Markdown，图片下到本地 images/，收藏与二次创作超方便。

它能帮你干啥

  • 输入 mp.weixin.qq.com 链接；
  • 自动抓正文 + 下载全部图片；
  • 生成 Markdown（图片用相对路径引用）。

3 步上手

  1. cd scripts && pip install -r requirements.txt；
  2. python main.py <文章URL>；
  3. 看生成的 output/标题.md + images/。

常见坑

  • 微信有反爬，失败就稍后重试；
  • 部分动态图可能抓不到；
  • 图片名用哈希避免重复。

进阶版 · 玩出花

进阶配置

可指定输出目录 python main.py <URL> ./my-articles；依赖 requests / beautifulsoup4 / lxml。

与其他工具组合

  • 配「去 AI 味」把抓来的长文润成你自己的声音；
  • 配「语雀 / IMA」推上去做知识库。

自动化玩法

批量丢一堆链接进脚本，一次性转成 Markdown 文库。

边界与注意

仅公开可访问文章；遵守平台与版权，别批量爬付费 / 授权内容。

多平台衍生钩子

  • 长文标题：《把公众号好文一键存成 Markdown：收藏与二创不再复制粘贴》
  • PPT 大纲（5 页）：封面 → 爬虫能干啥 → 安装与用法 → 组合玩法 → 行动号召
  • 短视频钩子（15s）：「看到好文章想留存？贴链接自动变 Markdown，图片也下好了。」
