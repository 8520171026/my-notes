## 项目结构
- `site/` —— 导航站（已发布为 GitHub Pages，gh-pages 分支）
  - `index.html` 总导航
  - `*.html` 各工具详情页（小白版 + 进阶版）
- `docs/` —— 各工具长文教程（Markdown，可直接发公众号 / 乐享）
- `ppt/` —— 各工具 PPT 大纲（多平台衍生素材）
- `scripts/` —— 各工具短视频口播脚本（多平台衍生素材）
- `assets/` —— 配图等素材

## 内容更新节奏
每掌握一个工具 → 出一页详情（导航站 + 长文）→ `git push` ＋ `git subtree push --prefix=site origin gh-pages` 重新发布，公开链接自动更新。
