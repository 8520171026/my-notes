## 项目结构
- `site/` —— 导航站（已发布为 GitHub Pages，gh-pages 分支）
  - `index.html` 总导航
  - `*.html` 各工具详情页（小白版 + 进阶版）
  - `combo-*.html` 组合玩法教程
- `docs/` —— 各工具长文教程（Markdown，可直接发公众号 / 乐享）
- `ppt/` —— 各工具 PPT 大纲 + 实做成品 `.pptx`
- `scripts/` —— 各工具短视频口播脚本
- `videos/` —— 实做短视频成品 `.mp4`
- `assets/` —— 配图等素材
