偏门神器 · 教育学习

Google Classroom 管理器

google-classroom-education
分类：教育学习 需OAuth配置 来源：skillhub.cn

小白版 · 3 分钟上手

一句话它是啥

通过 Google Classroom API 直接管课堂：列课程和花名册、查作业与提交、建/改作业、发公告、看成绩——老师/助教的管理外挂。

它能帮你干啥

  • 列出你名下课程、学生名单、教师名单；
  • 查看作业布置与提交情况、批改进度；
  • 确认后批量建作业、发公告；
  • 汇总成绩与提交状态，少切网页。

3 步上手

  1. 用 Google 账号完成 OAuth 授权（走 ClawLink 托管连接）；
  2. 用自然语言说要干啥（「给三年级甲班发个周末作业」）；
  3. 它调 API 帮你执行，改动类操作先确认。

常见坑

  • 需 Google Cloud OAuth 凭据 + ClawLink 托管，配置门槛较高；
  • 建/改作业属于写操作，执行前看清范围；
  • 学校账号可能限制 API 权限，先确认开通。

进阶版 · 玩出花

进阶配置

用 ClawLink 托管连接流做 OAuth，免去本地配凭据；可管理课程花名册、作业与提交、成绩、公告，支持批量建作业 / 发公告。

与其他工具组合

  • 配「学术文献 PPT」：作业要求 + 参考 slides 一键发；
  • 配「日历/邮件」类：截止日自动提醒学生；
  • 配「表格」类：成绩导出做分析。

自动化玩法

固定「周日晚发下周作业 + 截止前提醒 + 收齐后汇总成绩」的流水线。

边界与注意

强依赖 Google 账号 OAuth 与 ClawLink 托管，普通用户配置成本高；写操作务必二次确认。
