商务谈判

negotiation
分类：商务/谈判 即装即用 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

做商务谈判、报价博弈、合同条款拉扯时的结构化方法。

啥时候用它

谈价格、谈合作条款、处理对手不同风格、复盘谈判时。

它能帮你干啥

  • 核心原则
  • 评分框架
  • 常见情境处理
  • 对手风格识别
  • 表达与声量
  • 常见错误 + 快速诊断

常见坑

  • 别把它当万能生成器——它给的是结构化工作流，不是一键答案；
  • 无
  • 关键产出过质量门才交付，别跳过。

进阶版 · 玩出花

核心工作流

  1. 定核心原则
  2. 用评分框架评估
  3. 按情境处理
  4. 识别对手风格 → 调整打法
  5. 守表达纪律 → 快速诊断复盘

质量门怎么过

  • 不情绪化、看利益不盯立场
  • 有证据、有预案

边界与注意

无 它是方法论技能，越具体的输入产出越准；跨项目复用同一套框架即可。

多平台衍生钩子

  • 长文标题：《谈判别只会让价：用评分框架拿结果》
  • PPT 大纲（5 页）：封面 → 核心原则 → 评分框架 → 情境处理 → 对手风格 → 复盘
  • 短视频钩子（15s）：「一谈价就慌？用框架把谈判变成可复盘的动作。」
