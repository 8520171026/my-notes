Motu 人像调色引擎

motu-color-engine
分类：设计创作 需 MotuArt API 人群：进阶向

小白版 · 3 分钟上手

一句话它是啥

做视频/做号常要处理人像：调个色、磨个皮、换个证件照底色、批量出头像。Motu 就是个「AI 人像精修」引擎——丢一张照片进去，按你要的来。

它能帮你干啥

  • 人像调色 / 肤色校正（电影感、商业感 look）；
  • 保身份磨皮：只柔化毛孔瑕疵，脸型不变、不搞蛇精脸；
  • 导出皮肤 / 人脸 / 人物蒙版（抠图层）；
  • 证件照 / 护照照 / 签证照 / 头像：裁到规格、换底色、合规检查、冲印排版；
  • 合规换装：只换服务端审核过的服装，不乱来。

3 步上手

  1. 准备好要处理的照片；
  2. 对它说：「把这张调成电影感 + 磨下皮」或「出一套一寸证件照」；
  3. 它调 MotuArt 云端 API，吐回处理好的图。

常见坑

  • 它不是 WorkBuddy 内置能力，走 MotuArt 云端 API（需要网络，认证开启时要 Key）；
  • 单张图上限约 15MB，支持 JPG/PNG/WebP；
  • 换装只能用「审核过的服装目录」，不能自己编 prompt 乱换。

进阶版 · 玩出花

工作流：按活儿选脚本

底层是 MotuArt 托管的 HTTP API，自带一堆脚本，优先用脚本别手敲 curl。核心能力：

  • grade.sh — 调色 / 肤色校正，可顺带裁剪；
  • smooth.sh — 只磨皮，不动颜色白平衡；
  • mask.sh — 导出蒙版（skin / valid_skin / face / person）；
  • crop.sh — 只裁剪证件照/头像，可换底；
  • outfit.sh + outfits.sh — 先查审核服装目录，再换装；
  • id-pack.sh — 证件照整套：一张精修母版 → 多规格裁剪 + 上传优化 + 合规报告 + 冲印排版；
  • id-check.sh / optimize.sh / print-sheet.sh — 合规检查 / 上传体积优化 / 冲印排版。

证件照一条龙

id-pack.sh 会先出一张「调色+磨皮母版」，再从母版裁多个规格（护照、一寸、美签…），颜色和精修保持一致。支持学校/入学规格（上海义务教育、大学毕业图像、全国中小学生学籍等）。默认背景走各规格标准色板（白/蓝/红等）。

配「视频创作」一起用

  • 配 media-use：先用它把 BGM/图标备齐，人像精修交给 Motu，视频素材一条龙；
  • 配「PPT 演示文稿」：证件照/头像精修后直接拖进幻灯片；
  • 配「去 AI 味」：人像说明文案先去味，发布不尴尬。

边界与注意

引擎保身份——不做瘦脸、不变脸型、不换脸；磨皮只柔化皮肤区内毛孔。换背景仅限声明了 bg_colors 的规格。脚本失败先看 HTTP 状态码和错误详情，再决定重试/改参/问用户。处理是同步的，批量就是逐张调用。

多平台衍生钩子

  • 长文标题：《一张照片自动出证件照+换底色：AI 人像精修引擎实操》
  • PPT 大纲（5 页）：封面 → 人像后期痛点在哪 → 6 类能力 → 证件照一条龙 → 行动号召
  • 短视频钩子（15s）：「一张自拍自动出一寸照+换蓝底？这个 AI 精修引擎帮你搞定。」
