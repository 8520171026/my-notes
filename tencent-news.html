腾讯新闻

tencent-news
分类：资讯内容 即装即用（需配免费 Key） 人群：小白向

小白版 · 3 分钟上手

一句话它是啥

一个 7×24 在线的新闻情报兵——你开口问「今天有啥大事」「来份早报」，它就把腾讯新闻的热点、实时资讯、领域新闻整理好喂给你，还能顺手查天气。

它能帮你干啥

  • 不想刷信息流、又怕错过大事：直接问「今天热点」「本周 AI 圈发生了啥」；
  • 早报 / 晚报：早上来一句「给我今天的早报」，通勤路上秒掌握全局；
  • 领域追踪：指定「只看财经 / 军事 / 科技」，不走神在无关信息上；
  • 天气查询：顺手问「北京今天天气」，出行前心里有数。

3 步上手

  1. 首次用先配个免费 Key（去 news.qq.com/exchange?scene=appkey 拿，然后跟我说「把 Key 设上」）；
  2. 直接说人话：「今天有啥重要新闻？」「来份科技早报」「查下上海天气」；
  3. 它按热点 / 分类把标题、来源、摘要、原文链接整理好给你，点链接看详情。

常见坑

  • 不配 Key 拉不到新闻：这是最容易卡的点，去拿个免费 Key 设上就行（一次搞定）；
  • 它只走腾讯新闻自家的源，拉不到时会老实告诉你，不会拿别处内容糊弄你；
  • 「定时推送」要配合定时任务才能每天自动发，单次问是即问即答。

进阶版 · 玩出花

进阶配置

底层是 tencent-news-cli，所有调用走 run-cli 脚本（别手敲底层路径）；API Key 用 apikey-set KEY 配置、apikey-get 查看、apikey-clear 清除（Key 是裸值，不加引号）；版本过旧用 update 自升级，环境异常先跑 cli-state 看诊断 JSON。

与其他工具组合

  • 配「长文写作 / PPT」：先把今日热点抓来当选题和素材，再一键成文或成稿；
  • 配「去 AI 味」：新闻摘要润色后发公众号，不机械；
  • 配「AI 绘图」：挑一条热榜，配张封面图做短视频选题。

自动化玩法

接定时任务：每天早 8 点自动拉早报，做你的「信息早餐」；多领域（科技 + 财经 + 军事）分别定时，拼成一份私人简报。

边界与注意

只信自家源：CLI 拉取失败时明确报错、绝不回退到搜索引擎替代——这是设计原则；子命令和参数随版本变，实战以 help 实时输出为准；macOS 遇 Gatekeeper 拦 CLI，去「系统设置 → 隐私与安全性 → 仍要打开」放行即可。

多平台衍生钩子

  • 长文标题：《不想刷信息流？让 AI 每天给你煮一份新闻早报》
  • PPT 大纲（5 页）：封面 → 信息焦虑痛点 → 3 个核心能力（热榜/早报/领域）→ 真实用法 → 行动号召
  • 短视频钩子（15s）：「每天花 10 秒问一句，AI 帮你把天下事装进手机。」
