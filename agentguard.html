AgentGuard AI 安全守卫

agentguard
分类：偏门神器 需 Node 18+ 人群：进阶 / 运维安全

小白版 · 3 分钟上手

一句话它是啥

一个AI Agent 安全守卫——扫描你已装的技能有没有藏恶意代码、查凭据泄露、拦危险命令、跑每日安全巡逻，最后吐一份可视化健康报告。

它能帮你干啥

  • scan：扫技能/代码库，24 条检测规则揪出 SSH 密钥读取、远程加载、提示注入等风险；
  • action：评估某个运行时动作（命令/网络/Web3 交易）该放行、拒绝还是确认；
  • patrol：8 项每日巡检（技能完整性/凭据/网络暴露/cron/文件系统/审计日志/配置/信任注册表）；
  • checkup：5 维综合打分，生成带龙虾吉祥物的 HTML 健康报告。

3 步上手

  1. 装好（需 Node.js 18+，首次建议跑 `npm install` 装脚本）；
  2. 跑 /agentguard checkup 做整体体检；
  3. 看 Lobster 报告（90+ 肌肉男 / 70–89 拿盾 / 50–69 喝咖啡 / 0–49 包绷带）。

常见坑

  • 需 Node 18+，Web3 模拟可选 GoPlus API；
  • 它只读 ~/.ssh 权限不读密钥内容，安全审计不是密钥窃取；
  • OpenClaw 环境才能跑 patrol，其他环境用 scan/report 即可。

进阶版 · 玩出花

进阶配置

5 维评分权重：代码安全 25% / 凭据安全 25% / 网络系统 20% / 运行时防护 15% / Web3 安全 15%（未用 Web3 则重分配）。评级 S(90+)/A(70–89)/B(50–69)/F(0–49)。信任等级分 untrusted / restricted / trusted，配能力模型（网络白名单、文件系统白名单、exec 开关、Web3 链白名单）。

与其他工具组合

  • 配「 claws/沙箱」：把扫描结果接进 CI，装新技能前先过 AgentGuard；
  • 配「审计日志」：patrol 写入 ~/.agentguard/audit.jsonl，可做威胁态势分析；
  • 配「自动化 cron」：patrol setup 设成每日定时巡逻（支持 Telegram/Discord 通知）。

边界与注意

默认 balanced（拦危险+确认风险）；strict 全拦、permissive 只拦致命，按需调；扫描第三方代码只用它自带脚本，绝不当场执行被扫目标代码。
