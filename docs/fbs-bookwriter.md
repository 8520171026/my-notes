## 小白版（是什么 / 能干啥 / 3 步上手）
### 一句话它是啥
一套专为 **3 万字以上长文档** 设计的 AI 写作工具链——写书、写白皮书、写手册、写行业指南、写深度报道，从定大纲到成稿到质检，一条龙陪你跑完。

### 它能帮你干啥（说人话 + 场景举例）
- 想写本行业白皮书 / 分享手册 / 产品指南，但一上来就卡在「怎么开这个头」；
- 公众号想做深度长文系列，要结构、要查证、要能续写不跑偏；
- 把一堆散素材（笔记、访谈、资料）整理成有条理的书稿；
- 写完了还要过质检：事实对不对、段落通不通、AI 腔重不重——给你一份「哪里要改」的清单。

### 3 步上手
1. 跟我说「我要写一本关于 XX 的书 / 一份 XX 白皮书」，我启动福帮手，先帮你理清主题、读者、目录；
2. 进入写稿，它按章节逐篇产出，每章写完你确认再继续，不会一次性糊你一脸；
3. 成稿后自动过 S/P/C/B 四层质检，给你一份修改清单，改完好发布。

### 常见坑（小白最容易卡的地方）
- 它适合「长」文档（3 万字+），写个 500 字小红书没必要动用它；
- 主题是它的燃料——你给的方向越清楚，成稿越合心意；上来就「帮我写本书」它会先反问你一堆；
- 联网查证默认开（能补最新事实），没网会降级成本地规则，重要数据还是你核对。

## 进阶版（配置 / 组合玩法 / 自动化 / 边界）
### 进阶配置
背后是 **S0–S6 标准工作流**（素材→大纲→写稿→扩写→精修→质检→交付），每一步有门禁，不达标不往下一步走；支持 **8 大场景包**（通用 / 家谱 / 咨询 / 代撰 / 培训 / 自传 / 白皮书 / 调查报道），自动识别你写的体裁并切换策略。

### 与其他工具组合
- 配「去 AI 味」：长稿成稿后过一遍，发布前最后一道「人味」质检；
- 配「PPT 演示文稿」：把书里某章抽成幻灯片，做分享 / 培训；
- 配「腾讯新闻」：深度报道写完，改写成快讯发资讯渠道。

### 自动化 / 脚本玩法
- **跨会话恢复**：今天写一半关了，明天说「继续」它从原处接上，不丢进度；
- **联网反向核实**：自动查最新模型名 / 价格 / 法规，避免写出过时内容；
- **多格式交付**：成稿可导出 MD / HTML，直接进你的发布链路。

### 边界与注意
- 它是「手稿工具链」不是「代你思考」——核心主张、案例、观点得你给；
- 质检是机检辅助，正式发布前关键事实仍要你把关；
- 超长（50+ 章 / 200 万字）建议分卷执行，别一口气全量扫。
