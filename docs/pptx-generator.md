# PPT 演示文稿（pptx-generator）

- 工具名：PPT 演示文稿
- 英文名 / 命令：pptx-generator
- 分类：D 设计创作
- 人群标签：小白向
- 上手状态：即装即用

---

## 小白版

### 一句话它是啥
把「帮我做个关于 XX 的 PPT」这种话，直接变成一份能打开、能改的 PowerPoint 文件。

### 它能帮你干啥
- 不会排版、没模板、赶时间，用它一句话出初稿；
- 内置 11 种页面类型（封面、目录、图表、表格、时间线、图片页等）、5 套配色；
- 图表、表格、时间线、图片都能直接生成，不用自己拖。
- 场景：周报汇报、产品介绍、培训材料、活动总结——先出骨架，你再精修。

### 3 步上手
1. 对我说：「帮我做个关于《XX》的 PPT，面向 XX 人群，重点讲 XX」；
2. 它生成 `.pptx` 文件并给你预览；
3. 用 PowerPoint / WPS 打开，改字、换图、调色即可交差。

### 常见坑
- 第一次用会在后台装 Python 依赖（它自动处理，等几十秒即可）；
- 生成的是「结构初稿」，视觉精细度不如人工精修，适合赶工和打底。

## 进阶版

### 进阶配置
- JSON 驱动：可定义每页类型、标题、要点、图表数据，生成高度可控；
- 支持中文排版与多种版式，可指定配色方案。

### 与其他工具组合
- 配「去 AI 味」先润色文案，再进 PPT，避免一股 AI 腔；
- 配「文档转 Markdown」把资料 PDF/Word 先转成文本，喂给 PPT 当素材；
- 配「长文写作」先出报告大纲，再一键转成汇报 PPT。

### 自动化 / 脚本玩法
- 把生成命令接进定时任务，每周一自动出上周周报 PPT；
- 批量生成：一份数据 → 多套配色 → 多版本对比。

### 边界与注意
- 生成物是初稿，正式对外材料建议人工过一遍视觉与数据准确性；
- 超复杂定制（特殊动画、品牌模板）仍建议手做或后期加工。

## 衍生素材钩子
- 长文标题建议：《3 分钟用 AI 做出能交差的 PPT》
- PPT 大纲（5 页）：封面 → 痛点（熬夜做 PPT）→ 3 个核心功能 → 真实案例 → 行动号召
- 短视频脚本钩子（15s 开头）：「还在熬夜做 PPT？跟我说一句话，AI 帮你出初稿。」
